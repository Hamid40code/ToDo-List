# React To-Do List

A simple To-Do List app built with **React** and **Vite**.

> **Learning / Demo Project**  
> This is a personal learning project. The code is for practice and experimentation only — it is **not** production-ready.

### Features
- Draft → Submit workflow with reorder & delete
- Mark tasks as done / restore
- Active & Done tabs with counts
- Light / Dark theme (persisted)
- LocalStorage persistence
- Smooth animations & responsive design

### Tech Stack
React 19 · Vite · CSS (Custom Properties) · localStorage
